丰巢开屏跳过与广告 SDK 定向拦截试用版，使用 libxposed API 102。

- 跳过已确认的开屏 Activity，清理启动图片和窗口背景。
- 增加 TopOn、ToBid、Ubix 业务初始化封装拦截。
- 增加首页横幅、插屏、开屏的批量广告候选过滤。
- 不检查丰巢版本号；按实际类名和方法签名匹配。
- 默认关闭大范围 SDK 诊断日志。

安装要求：Android 8.0 及以上，支持 API 102 的 LSPosed。安装 APK 后启用 MyHook，作用域选择丰巢 `com.fcbox.hiveconsumer`，强行停止并重新打开丰巢。

验证：已在 Android 17 / LSPosed 2.2.1 / 丰巢 6.48.0 上确认六个 SDK Hook 安装成功、冷启动正常进入首页。原有 12 项跳转策略测试通过。

限制：SDK 拦截仍属试用，尚未捕获真实广告触发时的新增规则命中；不保证覆盖所有 SDK、子进程、WebView 广告或网络请求，支付、扫码取件等业务仍需继续验证。

APK 使用与先前本地版本相同的签名证书，可覆盖安装同证书版本。附带 `.sha256` 文件用于核对下载完整性。
